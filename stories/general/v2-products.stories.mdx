This video demo will help you to add Tour Details on V2 Product Cards on Prismic and add them in the Microsite, Alternatively read the steps below and get V2 Microsite up and running.

### Steps to Get Up and Running;

- **Step 1:** Create a Regular Microsite Document (do all the setup required, header/footer/meta...)
- **Step 2:** Open All Tours Tab,
  - **Step 2.1:** Create a `Detailed Product` Slice
  - **Step 2.2:** Add in all the required information, for adding Content Blocks, go-to the repeatable zone, select label and add the necessary content.
  - **Step 2.3:** Once You add all the Details of the Product, **Set the Ordering** for the Content Block you added in the `Contet Order` Section found at the top of `All Tours` tab
  - **Step 🔄:** repeat `Step 2.1, 2.2` for n number of tours. if you add different labels for subsequent content blocks, define the new label in the `Content Order` as you did in `Step 2.3`
- **Step 3:** You have successfully added tour details into the microsite, to make the tour show up on the Microsite use any of the existing Slices in `Description Tab` or `Categorized Tours` tab that describe itself as V2 (and above) tours element and set the TGID there.
