# Common Footer

The common footer is custom type document that can be linked to any microsite, content page or listicle page document.

## Steps to Get Up and Running:

After creating the Common Footer Document, fill in the Main tab with all the required fields at the least (marked with a \*)

Fields:

- `Prismic Preview Title`
  - Title that appears when browswing/searching documents on Prismic
- `Attration Name *`
  - This is name of the attraction that will appear in the disclaimer (if on)
- `Powered by Headout`
  - Toggle the 'by Headout' logo to appear beside the Microbrand logo on the footer
- `Microbrand Type`
  - Type of Microbrand ((A-C)(1-3)) used internally in code to change any element of the footer depending on the type of Microbrand
- `Invert Logo Color`
  - Will invert the logos color. Eg. if a black logo is added and this toggle is on then the logo will appear as white
  - Do not use when logo has any other color than black
- `Show Disclaimer`
  - Will show a disclaimer under the logo. Uses the `Attraction Name` field
- `Disclaimer Text`
  - Will override the default disclaimer text provided in the code
- `logo`

### Slice Zone

Currently has only 1 available slice to use;

`Footer Column`

Non Repeatable Zone:

- `Heading`
  - Heading of the links column

Repeatable zone:

- `Link Text`
  - Text of link
- `link`

Example:

<FooterColumn
  title={'Footer Column Heading'}
  links={repeat(
    {
      link_text: 'Google',
      link_type: {
        url: 'https://www.google.com',
        target: '_blank',
      },
    },
    5
  )}
/>
