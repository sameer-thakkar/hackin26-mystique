# Redirects

### Keywords

- Mystique - internal tech name for the code that handles all websites on Prismic

### Setting up a redirect

For any domain to have a redirect set up on it, it first needs to be set up on Mystique. (Request @mb-tech if this is not done)

- Change the UID of the existing document to the new UID (corresponding to the new URL) on prismic.
- Update the page URL to the new URL too. This needs to contain https:// (or http://). _Note:_ Will not work if this has not been setup correctly
- Set the redirect type to either 302 or 301 (defaults to 302)

Superb! you are done 🥳

### Other Redirects

These other redirects should be avoided and are not recommended, but if you still need to use them, they are available.

There are 2 levels of redirects that can be set up:

#### Domain level

This will redirect any domain to the new URL it is pointing to. For example, if [www.vaticantickets.org](http://www.vaticantickets.org) has a domain level redirect set up for it (to www.headout.com) then all URLs with www.vaticantickets.org (regardless of the fact if they are microsites or content pages) will be redirected.

Steps to set up (using the above example):

- Create a new redirect document on Prismic.
- Add the UID as the URL that needs to be redirected, without `https://` (in this case; www.vaticantickets.org)
- Add the redirect url as the url that it needs to be redirected to, with `https://` (in this case; https://www.headout.com)

#### Microsite level

This will redirect any microsite and all its _referenced_ content pages to the new URL it is pointing to. For example, if [https://www.vaticantickets.org/papal-villas/](https://www.vaticantickets.org/papal-villas/) has a Microsite level redirect set up then all the content pages it references will be redirected to the new URL. https://www.vaticantickets.org will remain unaffected.

Steps to set up (using the above example):

- Go to the Microsite document on Prismic, in this case to [https://www.vaticantickets.org/papal-villas/](https://www.vaticantickets.org/papal-villas/) document.
- Now in the 'Main' section, you will see a field called 'Redirect URL'.
- Type in the URL (with `https://`) in this field.
